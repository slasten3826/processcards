## 1. Объём

Правка узкая: сужается **множество легальных целей**, всё остальное остаётся.

```text
меняется   legal_encode_card_ids
не меняется фаза выбора, механика обмена, привязка к шагу
```

`ENCODE` уже стоит на `EFFECT` и уже открывает целевую фазу через `pending_encode_choice`. Новых сущностей не появляется.

## 2. Что сейчас

```text
turn.lua legal_encode_card_ids

maybe_add    добавляет карту, ЕСЛИ она не revealed
источники    топдек, затем targets, затем latent
```

То есть текущий набор — «не открытые карты из трёх зон».

## 3. Что должно стать

```lua
local function legal_encode_card_ids(state)
    -- ENCODE_SWAP_LAW: латентный ряд целиком, без условий на
    -- информационное состояние. Топдек и целевая зона выходят из области.
    local legal = {}
    local zone = state.zones.latent
    for slot = 1, zone.slot_count do
        local card_id = zone.cards[slot]
        if card_id then
            legal[#legal + 1] = card_id
        end
    end
    return legal
end
```

Два изменения относительно текущего: снят фильтр `is_revealed`, убраны `deck` и `targets`.

## 4. Механика обмена

Не трогается. `confirm_encode_target` уже делает общий обмен через зону и слот:

```text
remove_from_current_zone(first)
remove_from_current_zone(second)
place_card(first,  second_zone, second_slot)
place_card(second, first_zone,  first_slot)
```

Обе карты теперь всегда в `latent`, поэтому ветка `zone == "deck" and nil or slot` перестаёт срабатывать. Удалять её в этом срезе **не нужно**: она безвредна и уйдёт вместе с общей машиной фаз.

## 5. Информационное состояние

Обмен позиций **не меняет** `info_state` ни одной из карт. `revealed` карта остаётся `revealed` на новом месте, `known` остаётся `known`.

Это важно для `FLOW`: перемещённая `known` карта продолжает работать якорем в кольце, просто в другой позиции.

## 6. Что проверить

```text
1. набор целей = ровно занятые слоты латентного ряда
2. revealed латентная карта ПРИСУТСТВУЕТ в наборе
   (сейчас отсутствует — это и есть снятие фильтра)
3. топдек ОТСУТСТВУЕТ в наборе
4. карта целевой зоны ОТСУТСТВУЕТ в наборе
5. после обмена: карты поменяли слоты, info_state у обеих не изменился
6. после обмена доска замкнута, счётчик латента не изменился
7. обмен карты самой с собой невозможен либо безвреден
```

Пункт 2 — единственный, который **расширяет** права игрока; остальные сужают.

## 7. Ожидаемое расхождение эталона

```text
minor_*   ожидается расхождение: ENCODE достижим в trump-free
full_*    ожидается расхождение
```

Характер: исчезают обмены с участием топдека и целевой зоны, появляются обмены с участием открытых латентных карт.

Если расхождения **нет вообще** — значит матрица не доходит до `ENCODE`, и это ложная зелень, а не успех. Проверить наличием событий обмена в трассах до и после.
