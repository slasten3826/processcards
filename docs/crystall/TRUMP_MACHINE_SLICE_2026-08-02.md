## 1. Что этот срез фиксирует и чего НЕ фиксирует

```text
ФИКСИРУЕТ   раму: четыре шага машины, бюджеты,
            дескриптор, швы с ЧЕТЫРЬМЯ соседями
НЕ ФИКСИРУЕТ такты внутри RESOLVE
```

```text
очередь и камера СЮДА НЕ ВХОДЯТ с 2026-08-05
```

Они переданы модулю потока: `TRUMP_MACHINE_LAW §3` редакции 2, контракт — `TRUMP_FLOW_MODULE_SLICE_2026-08-05`. Машина к ним **обращается**: `hand_out` на шаге `DRAIN`, `take_back` после `RESOLVE`, `close` в конце разрядки.

Это не пробел, а прямое следствие `TRUMP_MACHINE_LAW §2`:

> Перечислить такты заранее нельзя: у события нет общей длины. Перечислить шаги машины — можно, и они уже перечислены.

Козыри разные, и что происходит внутри `RESOLVE` у каждого своё. Оно приходит **вместе с картой**, а не заранее, и складывается в реестр `§9`, который по `TRUMP_MACHINE_LAW §11` есть перечень фактов, а не закон.

```text
рама пишется один раз. Нутро прирастает по строке на козыря
```

## 2. Четыре шага машины

`TURN_STEP_LAW §9`. Цикл повторяется, пока очередь не пуста.

```lua
-- src/core/trump_machine.lua
M.drain(state)   -- разрядить очередь досуха. Шаг 8 хода
```

```text
DRAIN    взять голову очереди
RESOLVE  такты козыря. Их число задаёт дескриптор, §3
REPAIR   вернуть целостность доски
STORE    в козырную камеру; третий даёт reset pulse
```

Шаги фиксированы и не зависят от карты. Порядок внутри цикла — `TRUMP_RESOLUTION_ORDER_LAW`: очередь, не стек, `first caused, first resolved`.

```text
козырь, порождённый во время RESOLVE, встаёт в ХВОСТ той же очереди
```

## 3. Дескриптор

`TRUMP_MACHINE_LAW §6` делает его обязательным. Форма предложена `TRUMP_TARGETING_AXES §4` и закрепляется здесь:

```lua
-- src/core/trump_descriptors.lua
PURGE = {
    edge          = {"LOGIC", "MANIFEST"},
    targets_state = "revealed",
    zones         = {"manifest", "latent", "topdeck"},
    pick          = "all",
    tacts         = "computed",
}
```

Поля:

```text
edge           пара операторов. Идентичность, TRUMP_IDENTITY_LAW §3
targets_state  hidden | known | revealed | any | nil, если не целит
zones          ПЕРЕЧЕНЬ зон. Незаявленная зона НЕДОСТУПНА
pick           число | "all" | "chain" | "capacity" | "meta"
tacts          число | "computed"
```

Две оси прицела объявляются **раздельно** — состояние и зона. Основание `TRUMP_TARGETING_AXES §2`: множества пересекаются, но не равны, и разойдутся на открытой латентной карте, которая `revealed`, но не в манифесте.

```text
"все revealed"     состояние, живёт в нескольких зонах
"манифестный слой" зона, в которой не бывает не-revealed
```

Сегодня они почти совпадают, поэтому ошибка проявится не при написании, а через недели, в чужой партии.

## 4. Зоны есть таблица маршрутизации

`TRUMP_MACHINE_LAW §6`. Это главное, ради чего дескриптор обязателен:

```text
трогает latent    -> через модуль деки
трогает targets   -> TARGET_ZONE_LAW, долив через деку
трогает manifest  -> через минорную машину
трогает runtime   -> через минорную машину
```

```text
незаявленная зона НЕДОСТУПНА
```

Без объявления козырь лезет в зону напрямую и заводит там свою копию чужой работы. Именно так прототип получил три копии операций деки.

## 5. Три рода, которые не прицел

`TRUMP_TARGETING_AXES §6`. Их нельзя выразить парой «состояние + зона», и дескриптор обязан их различать через `pick`:

```text
ёмкость   HALT сужает trump flow, TIGEL расширяет trump zone
мета      REPEAT: его прицел — ЧУЖОЙ козырь, а не карта
размер    GRANT добавляет колонку, то есть меняет размер зоны manifest
```

`pick = "capacity" | "meta"` объявляет род явно. `GRANT` остаётся открытым — `§13.3`.

## 6. Шов с механизмом выбора

`TRUMP_MACHINE_LAW §5`: козырная машина механизм **потребляет, не изобретает**.

```lua
choice.open(state, kind, ctx)   -- MINOR_MACHINE_SLICE §5
```

Козырь, требующий выбора, объявляет его позициями того же вида, что и минорный оператор. Своих `arm_`/`confirm_` у козырей не появляется **ни одного**.

```text
минимум пять козырей требуют выбора игрока:
EJECT, ORACLE, UNBOUND, SWAP, WARRANT
механизмов в прототипе: ноль
```

`ORACLE` ред. 2 — шесть позиций вида `card`, где порядок `picked` и есть ответ. Механизм эту форму уже держит: `MINOR_MACHINE_SLICE §3`.

## 7. Шов с модулем деки

После `DECK_MODULE_LAW §5.1a` модуль деки козыря **не отправляет**. Он возвращает его просителю вместе с классом, и маршрутизирует проситель.

```text
asker = "trump"   козырная машина просит карту, получает card_id и класс
                  класс "trump" -> сама ставит его в очередь
```

Обратная стрелка отсутствует по построению: `deck.lua` не требует `trump_machine.lua`, поэтому `trump_machine.lua` требовать `deck.lua` **может**. Это и есть причина, по которой три копии в `trump.lua` становятся удаляемыми.

## 8. Бюджеты

`TRUMP_MACHINE_LAW §3`: бюджеты цикла принадлежат машине, их **сброс** — слою транзакции.

```text
глубина цепочки        state.trump_chain_steps
попытки починки        state.trump_repair_attempts
сброс                  transition.begin, TRANSITION_SLICE §6
```

```text
цикл не может длиться дольше одного действия игрока
```

Проверка 9 среза транзакции уже стоит на этом и обязана пережить настоящий переезд.

Исчерпание бюджета выставляет признак `state.trump_runaway`, который `finish` превращает в ошибку действия и который **переживает** закрытие: `TRANSITION_SLICE §7`. Терминальность признака — `TURN_STEP_LAW §13.2`, открыта.

## 9. Реестр тактов

`TRUMP_MACHINE_LAW §11`.

```text
двадцать две таблицы   по одной на козыря, docs/table/trumps
один РЕЕСТР            растущий, по строке по мере манифестации
```

```text
реестр НЕ пишется заранее: часть значений вычисляема
```

Стартовое наполнение — карта из `TRUMP_TARGETING_AXES §5`, **сверенная с карточными документами**, а не с однострочниками обзора. Что изменилось после сверки:

```text
WARRANT   §7.1 axes ЗАКРЫТ: WARRANT ред. 2 сузился до
          «любая RAСКРЫТАЯ карта». zones — где лежит revealed,
          targets_state = "revealed", pick = 1
SWAP      §7.2 axes ЗАКРЫТ: SWAP §4 — zones = {"targets", "trump"}
ORACLE    ред. 2: прото-рука, шесть возвращаются, шестая
          становится вершиной, затем обычный добор.
          Строка "6->1" в карте устарела
ENCODE    не козырь; в карте не участвует
```

Остальные строки карты помечены `док` и **не** сверены с кодом. Они входят в реестр по мере манифестации козыря, а не оптом.

## 10. Вырожденные случаи

```text
очередь пуста при DRAIN        цикл не начинается, событие не эмитится
козырь без дескриптора         nil, "undeclared_trump". НЕ резолвится
дескриптор без zones           допустим только при pick = "meta"
                               или "capacity"
трогает незаявленную зону      nil, "undeclared_zone"
RESOLVE породил козыря         в ХВОСТ той же очереди, не в голову
бюджет исчерпан                trump_runaway, цикл прекращается
доска не закрыта               резолв НЕ начинается, BOARD_CLOSURE_LAW §1
```

Вторая строка несущая: нереализованный козырь обязан отказать **громко**. Сегодня двенадцать из двадцати двух работают, а десять молчат.

## 11. Проверки среза

```text
1.  DRAIN на пустой очереди      цикл не начинается
2.  порядок очереди              first caused, first resolved, не LIFO
3.  козырь из RESOLVE            встал в ХВОСТ, разрядился в том же шаге
4.  козырь без дескриптора       nil, "undeclared_trump"
5.  незаявленная зона            nil, "undeclared_zone"
6.  дескриптор capacity без zones допустим
7.  доска не закрыта             резолв не начался
8.  бюджет цепочки исчерпан      trump_runaway выставлен, цикл прекращён
9.  КОНТРОЛЬ: бюджет сброшен
    новым действием              следующее действие резолвит нормально
10. STORE третьего козыря        камера разряжается в деку
11. козырь просит выбор          использует choice.open, своего arm нет
12. козырь просит карту у деки   asker = "trump", класс возвращён
13. СТРУКТУРНАЯ: arm_/confirm_
    в trump_machine.lua          ноль
14. СТРУКТУРНАЯ: pop_topdeck
    вне deck.lua                 ноль. Смерть трёх копий
15. СТРУКТУРНАЯ: каждый
    реализованный козырь         имеет строку в дескрипторах
```

Что ловит каждая:

```text
2, 3   очередь против стека. Третья — то самое «прерывать некого»
4      громкий отказ нереализованного. Сегодня десять молчат
5      таблица маршрутизации работает. Без неё козырь лезет в зону сам
8, 9   бюджет ЗА ДЕЙСТВИЕ. Девятая — контроль: без неё липкий бюджет
       убил бы вторую цепочку в партии и это списали бы на дисперсию
11     механизм ПОТРЕБЛЯЕТСЯ, а не изобретается заново
13-15  единственность. Пятнадцатая ловит козыря, реализованного
       в обход дескриптора
```

## 12. Порядок

```text
1. дескрипторы: файл + двенадцать реализованных козырей
2. рама: drain, четыре шага, бюджеты, очередь
3. перевод двенадцати реализованных на раму, по одному
4. проверки §11
5. УДАЛЕНИЕ трёх копий из trump.lua
6. десять нереализованных — по одному, каждый со своей строкой
   в реестре и своими тактами
```

Пункт 6 бесконечен по построению и это нормально: рама к нему готова, а такты приходят с картой.
