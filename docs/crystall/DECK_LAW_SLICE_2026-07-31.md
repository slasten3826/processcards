
Не входит: `CANON` (не манифестирован), `FOOL` и `☰ CONNECT` (уже соответствуют `§7`), переполнение камеры (уже прячет).

## 2. Сокрытие при входе в тело деки

`DECK_LAW §2`. Единственная точка, где карта попадает в позицию кольца:

```lua
-- turn.lua
local function ring_set_card(state, position, card_id)
```

Контракт:

```text
position.zone == "latent"                    состояние не меняется
position.zone == "deck", НЕ вершина          state_lib.hide_card
position.zone == "deck", вершина             состояние не меняется
```

Вершина определяется как `position.index == #state.zones.deck.cards`. По `DECK_LAW §3` `known` там законен, поэтому вершина из правила исключена.

```text
сокрытие живёт в ring_set_card, а не в flow_ring_rotate
```

Причина: `ring_set_card` — единственное место укладки в кольцо, и правило про тело деки принадлежит **позиции**, а не оператору. Оператор, добавленный позже, получит его даром.

## 3. Вытеснение прячет

`HALT_MODE_LAW §4` ред. 2: вытеснение `HALT` и переполнение камеры подчиняются одному правилу.

```lua
-- trump.lua
local function shuffle_into_deck_keeping_state(state, card_ids, event_name)
```

```text
имя ЛОЖНО после правки: состояние больше не сохраняется
переименовать в shuffle_into_deck
добавить state_lib.hide_card перед place_card
```

Переполнение камеры (`M.resolve_trump_zone_entry`) уже прячет и не меняется. После правки обе двери делают одно и то же — их слияние в одну функцию допустимо, но не обязательно в этом срезе.

## 4. Отправка минора с топдека

`DECK_LAW §6`: раскрытая карта уходит по классу. `§7`: назначение задаёт операция.

**UNVEIL**, `trump.lua`, `unveil_topdeck`:

```text
было    if not class_is(trump) then return end        минор ОСТАЁТСЯ
станет  if not class_is(trump) then
            reveal_minor_to_grave(state, card_id, "UNVEIL topdeck")
            return
        end
```

`reveal_minor_to_grave` уже существует в `trump.lua` и эмитит `deck_reveal_to_grave`.

**MANIFEST**, `turn.lua`, `confirm_unrevealed_target`, ветка `else`:

```text
было    реveal_card, затем ветка только для class == "trump"
станет  добавить: source_zone == "deck" и class == "minor"
                  -> move_to_grave(state, card_id)
```

`move_to_grave` уже существует в `turn.lua` и делает `remove + reveal + place(grave)`.

```text
следствие, названное DECK_LAW §7: MANIFEST получает возможность
расходовать деку по одной карте за ход
```

## 5. Снос PAIR_CARD

`PAIR_CARD_LAW` помечен `LEGACY`. Механизм и так недостижим: `pending_pair_card_choice` не присваивается нигде в `src/`.

Это удаление, а не переписывание. Поведение игры не меняется, потому что достижимого поведения не было.

## 6. Вырожденные случаи

```text
кольцо, подвижных < 2        rotate не вызывается, ring_set_card тоже
вершина деки известна        сокрытие её НЕ касается, DECK_LAW §3
латент целиком раскрыт       вращается только дека, FLOW_RING_LAW §8.1.
                             Карта из тела в тело: уже скрыта, hide идемпотентен
UNVEIL на пустой деке        unveil_topdeck выходит по card_id == nil
MANIFEST на карте НЕ из деки latent, manifest, grave, runtime, play, targets

```

## 7. Проверки среза

```text
1. после вращения в теле деки нет ни одной known карты
2. после вращения в теле деки нет ни одной revealed карты
3. КОНТРОЛЬ: известная карта на ВЕРШИНЕ остаётся известной
4. вытесненные HALT-ом козыри входят в деку скрытыми
5. UNVEIL на миноре-вершине -> минор в могиле, дека короче на 1
6. MANIFEST на миноре-вершине -> то же
7. КОНТРОЛЬ: MANIFEST на миноре в ЛАТЕНТЕ -> в могилу НЕ уходит
8. СТРУКТУРНАЯ: pending_pair_card_choice отсутствует в src/
9. СТРУКТУРНАЯ: hide_card присутствует в ring_set_card
```

Что ловит каждая:

```text
1, 2   тихое нарушение DECK_LAW §2. Доска валидна, партия идёт,
       ошибка проявится поздней игрой через анкеры в кольце
3      переусердствование: сокрытие, накрывшее вершину, отняло бы
       у игрока единственное окно знания в деке
4      возврат к поведению редакции 1 HALT
5, 6   невыполненное DECK_LAW §7
7      обратное переусердствование: правило про топдек,
       расползшееся на другие зоны
8      забытый остаток мёртвого механизма. Прогоном не ловится:
       код не исполняется, но существует
9      правило, вынесенное из ring_set_card обратно в оператор
```

Проверки 1-7 поведенческие и строятся расстановкой: `reached = "planted"`. Проверки 8-9 структурные, читают текст исходника.

## 8. Ожидаемое расхождение эталона

```text
ожидается
```

Сокрытие при вращении меняет информационное состояние карт, а `UNVEIL` и `MANIFEST` меняют состав деки и могилы. Трассы разойдутся на партиях, где эти пути исполняются.

```text
эталоны перезаписываются ПОСЛЕ зелёных проверок §7, не до
```

Эталоны уже разошлись по `STEP_CHECK_SLICE §7` от 2026-07-30 и не были перезаписаны. Обе перезаписи делаются одной операцией.
