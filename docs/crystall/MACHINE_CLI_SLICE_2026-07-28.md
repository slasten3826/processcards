## 1. Несущее решение: сессия хранится журналом, а не состоянием

```text
сессия = сид + режим козырей + упорядоченный журнал записей
```

Каждая команда загружает журнал, создаёт новую игру от сида и **переигрывает** журнал целиком. Ничего от состояния на диск не пишется.

Почему так:

```text
детерминизм    гарантирован построением, а не проверкой
undo           бесплатен: отбросить хвост журнала
plant          воспроизводим наравне с ходами
формат         одна строка на запись, читаемо и диффится
```

Цена — переигрывание на каждую команду. При партии в сотню записей это доли секунды: `headless` проходит 200 шагов мгновенно.

## 2. Формат журнала

```text
.session/current.log

# seed=7 trumps=full
do commit:3
do hand:MINOR-8
do advance
plant MINOR-45 latent 2
do op:CYCLE
do advance
```

```text
строка "# ..."   заголовок, ровно один, первый
строка "do X"    действие игрока, идёт через протокол
строка "plant X" отладочная расстановка, минует протокол
```

Каталог `.session/` добавляется в `.gitignore`.

## 4. Переигрывание

```lua
function M.load()          -- читает журнал, возвращает {seed, trumps, entries}
function M.rebuild(log)    -- новая игра от сида, применяет все записи по порядку
                           -- возвращает game, а также накопленные события
function M.append(entry)   -- дописывает строку и НЕ переигрывает
```

`rebuild` собирает события всех записей в один список, чтобы `trace` мог их сгруппировать без повторного прогона.

## 5. Грамматика действий

```text
commit:<slot>
hand:<card_id>
op:<OPERATOR>
target:<ref>          ref = card_id для известных, H<n> для скрытых
tslot:<slot>
dir:left|right
advance
trump
draw
clear:selection|committed|armed
```

Правка от 2026-07-28: `dir` и `draw` в первой редакции отсутствовали. `arm_direction` — отдельный вид действия в протоколе, без него часть целевых фаз недостижима; пропуск был дырой в грамматике, а не решением.

`target` с ручкой `H<n>` разрешается через `view.resolve_handle` по наблюдению **текущей** позиции. Идентификатор скрытой карты в журнале не появляется.

`hand:<card_id>` использует идентификатор законно: рука принадлежит игроку и видна ему целиком.

## 6. Команды и поверхности

```text
команда              поверхность   источник
session new          —             создаёт журнал
session show         честная       view.observe + view.format
session fits         честная       рука + открытый манифест
session do           честная       протокол; ручки через build_action
session trace        честная       поток событий
session metrics      честная       позиция
session undo         —             усечение журнала
session plant        ОТЛАДКА       прямая мутация состояния
card / find          ОТЛАДКА       прямое чтение store
```

Отладочные команды печатают первой строкой:

```text
DEBUG SURFACE: full information
```

## 7. Расстановка

```lua
function M.plant(game, card_id, zone, slot)
```

Обязательства по закону §3:

```text
1. запомнить прежнюю зону и слот
2. state_lib.remove_from_current_zone
3. поместить в целевую зону и слот
4. восполнить прежний слот:
       manifest  -> draw.open_manifest_closure
       latent    -> draw.concealed_refill
       targets   -> draw.concealed_refill
       остальные -> ничего
5. если восполнение вернуло nil -> напечатать
       PLANT WARNING: hole left at <zone>[<slot>], deck empty
```

Правка от 2026-07-28: первая редакция не сказала, что делать, если целевой слот занят. Ответ — **обмен**:

```text
слот свободен   переложить и восполнить оставленную дыру
слот занят      поменять карты местами; занимавшая слот карта уходит
                туда, откуда пришла посаженная
```

Обмен ничего не восполняет и не может: размер каждой зоны при нём не меняется по построению. Это делает вторую форму строго безопаснее первой, а не особым случаем.

Информационное состояние: карта кладётся в состоянии, естественном для целевой зоны — `revealed` для `manifest`, `hand`, `grave`, `runtime`, `trump`; `hidden` для `latent`, `targets`, `deck`. Явное переопределение — четвёртым аргументом.

## 8. Таблица совпадений

```lua
for each card in hand:
    fit    = слоты, где rules.full_pair_fit(manifest[slot], card)
    joker  = слоты, где rules.move_legal(...) истинно, а full_pair_fit — нет
```

Вывод:

```text
MINOR-71   FLOW/CYCLE       fit:[1,3]     joker:[]
```

Разделение `fit` и `joker` обязательно: это два разных права, и второе стоит эффекта хода.

## 9. Трасса

```text
группировка   по turn_closed
внутри хода   события в порядке появления
отметка       строка-разделитель на step_spend_end
классы        козырные события помечены слева
```

Требование закона «аномалия заметна глазом» означает: разделитель ходов виден, козырное отделено от минорного, без внешних фильтров.

## 10. Метрики

```lua
legal_actions      #core.enumerate_legal_actions(game)
legal_pairs        число пар (карта руки, слот) с full_pair_fit
locked             legal_pairs == 0 и рука не пуста
joker_available    есть ли ☶ в руке или в runtime
trump_density      козырей в деке / #деки
zones              размеры всех зон
```

Всё считается по текущей позиции. Ничего, что требует прогона, сюда не добавляется.

## 11. Undo

```lua
session undo [n]   отбросить n последних записей вида "do" или "plant"
```

Заголовок не трогается. Реализуется усечением журнала, поэтому переигрывание даёт результат, неотличимый от прямой игры — требование закона §7 выполняется по построению.

`save` и `load` — копия файла журнала под именем.

## 12. Проверки среза

```text
1. new + do + show    состояние соответствует применённым действиям
2. одинаковый журнал дважды -> одинаковое состояние
3. undo 1 -> состояние равно состоянию до последней записи
4. plant карты из manifest -> слот восполнен, доска замкнута
5. plant при пустой деке -> предупреждение напечатано
6. show не содержит ни одного идентификатора скрытой карты
7. target:H<n> применяет действие к правильной карте
8. fits: joker-слоты присутствуют только при ☶ в руке или runtime
9. metrics.locked истинно ровно тогда, когда legal_pairs == 0
```

Пункт 6 проверяется тем же способом, что `audit_view`: ни один идентификатор карты с `info_state == "hidden"` не встречается в выводе.
