# Logic Joker Law

Статус:

```text
canonical table law
current LOGIC branch
supersedes the operator effect described in operators/LOGIC.md
amends MOVE_FIT_LAW with one exception
```

Этот документ фиксирует новое чтение оператора:

```text
☶ LOGIC
```

## 1. Core claim

`☶ LOGIC` перестаёт быть эффектом.

Он становится **пропуском**.

```text
LOGIC = сыграй карту куда угодно, нарушив топологию.
        Это и есть действие.
```

Ключевое отличие от всех остальных операторов: у `☶` **нет разрешения после хода**. Он не резолвится ни до мирового обновления, как `☷ DISSOLVE`, ни после, как остальные восемь.

Он происходит **в процессе** — в момент проверки легальности хода.

Короткая формула:

```text
девять операторов делают что-то, когда ход уже собран
LOGIC делает так, чтобы ход собрался
```

## 2. Почему прежнее чтение было неверным

Прежний `☶` менял видимую карту поля с картой руки. Это глагол `☳ CHOOSE` с довеском: CHOOSE тащит видимое в руку, LOGIC тащил видимое в руку и клал своё обратно.

То есть единственный оператор, чьё имя не описывало действие. В каноне ядро `☶` это `rules(x)`, во всех остальных слоях стека LOGIC проверяет и обосновывает. Обмен материей — территория `☳` и `☰`.

## 3. Почему джокер не может быть эффектом

Попытка сделать джокер обычным эффектом оператора замыкается в круг:

```text
чтобы разыграть карту, ход обязан пройти fit-проверку
оператор выбирается уже ПОСЛЕ того, как ход собрался
значит при несошедшемся fit до выбора LOGIC дойти нельзя никогда
```

Джокер, легализующий ход, не может быть эффектом того хода, который он легализует.

Поэтому `☶` переносится из фазы эффекта в фазу проверки.

## 4. Core law

```text
LOGIC JOKER

1. При проверке fit по MOVE_FIT_LAW: если ☶ доступен игроку на этот ход,
   карта руки закрывается против committed manifest-card
   без проверки смежности.

2. Если ход был собран через это исключение,
   оператором хода обязан быть ☶.

3. ☶ не производит эффекта. Ход разрешается обычным мировым обновлением
   и обычным уходом сыгранной карты в grave.
```

Пункт 2 самоисполняющийся: при несошедшемся fit `☶` остаётся **единственным легальным оператором** этого хода. Никакого учёта обещаний не требуется.

## 5. Цена

Цена джокера — **оператор хода**.

Все прочие карты дают выбор из двух операторов и эффект. Карта, сыгранная как джокер, не даёт ничего, кроме самого хода.

```text
обычный ход:  вмешательство + эффект
ход-джокер:   вмешательство, и только
```

Это не ослабление. Ход сам по себе проворачивает машину:

```text
committed manifest -> grave
latent -> manifest
deck -> latent, закрыто
сыгранная карта -> grave
```

То есть джокер покупает **право сделать ход, которого не существовало**, и этот ход двигает мир так же, как любой другой.

### 5.1. Эффект тратится самим ходом

Формулировка «в процессе» механическая, а не стилистическая. Легализация **и есть** расход эффекта: после неё тратить уже нечего.

Отсюда следует главное свойство карты с `☶`:

```text
карта с ☶ даёт два ВЗАИМОИСКЛЮЧАЮЩИХ применения на один ход,
и какое из них доступно, решает не игрок, а топология

топология сошлась     обычная карта: полный выбор оператора и эффект
топология не сошлась  пропуск: эффекта нет
```

Бесплатного эффекта не возникает ни в одном случае. Карта `☶☴` не может легализоваться через `☶` и затем сыграть `☴`: при несошедшемся fit `☶` остаётся единственным легальным оператором.

Ценность `☶` поэтому **ситуативная**. Она растёт ровно тогда, когда рука не подходит ни к чему.

## 6. Отношение к закону дублей

`MOVE_FIT_LAW §8`: дубль руки обязан состыковаться обоими портами, то есть обычно дубль **сужает** ворота.

`☶☶` — единственный дубль, который ворота **открывает**.

Но важное различение:

```text
любая карта с ☶      универсальный ключ, сохраняющий второе применение
                     через свой второй оператор
☶☶                   ключ и только ключ
```

Из этого не следует, что `☶☶` сильнейшая карта колоды. Открывать двери в этой игре **не обязательно**: вместо обхода топологии есть девять операторов с настоящими эффектами. Карта, умеющая только открывать, платит тем, что больше не умеет ничего.

`☶` встречается на 19 картах из 100. Ключом является каждая из них; чистым ключом — одна.

## 7. LOGIC на столе

Лежащая в `manifest` или `latent` карта с `☶` не имеет никакого особого статуса. Она участвует в топологии как любой другой оператор: соседством, самосвязью, сужением ворот при дубле.

```text
джокерность принадлежит руке, а не столу
```

## 8. Отношение к runtime

`RUNTIME` выдаёт оператор как дополнительный выбор на будущие ходы. По пункту 4 джокер срабатывает, когда `☶` **доступен игроку на этот ход** — с карты руки либо из `runtime`.

Следствие:

```text
LOGIC, установленный в runtime = каждая фиксация проходит без проверки геометрии,
                                 пока он там стоит
```

Цена остаётся прежней: за каждый такой ход оператором обязан быть `☶`, то есть эффекта в этот ход не будет. Плюс потрачены слот `runtime` и ход на установку.

Это самая крупная покупка в игре: `MOVE_FIT_LAW` для игрока фактически перестаёт действовать, пока он платит эффектом каждый ход. Пункт объявляется каноном, но помечается как первый кандидат на проверку плейтестом.

## 9. Что этот закон отменяет

```text
operators/LOGIC.md §1  «☶ = swap one revealed minor-card with one card from hand»
operators/LOGIC.md §3  current playtest law, вся процедура обмена
operators/LOGIC.md §4  legal target class

MOVE_FIT_LAW           дополняется исключением из §4 (no orphan operator)
                       и §3 (full pair fit) для случая, когда ☶ доступен
```

Старые документы не удаляются. `operators/LOGIC.md` подлежит пометке `superseded by LOGIC_JOKER_LAW.md` при следующем проходе по operator-слою.

Отдельное следствие: `☶` **теряет grave**. Прежний обмен мог целить `grave`; джокер не целит ничего.

## 9.1. Рассмотрено и отклонено

Обсуждалось общее правило:

```text
оператор, которым ход стал легален,
не обязывает играть эффект именно этого оператора
```

Отклонено по двум причинам.

**Оно пусто в текущей машине.** `MOVE_FIT_LAW §3-4` требует закрытия **обоих** операторов и запрещает сироту, поэтому «оператор легальности» как отдельная сущность не существует: легальность даёт пара целиком. Выбор любого из двух операторов и так свободен.

**Осмысленным оно становится только при ослаблении fit до одного оператора** — то есть при отмене no-orphan law. Но именно этот закон делает топологию обязывающей. Если достаточно одной стыковки, легально становится почти всё, ворота перестают закрываться, и **джокер обесценивается в тот же момент**: ключ имеет ценность только там, где есть запертые двери.

Вопрос «не слишком ли жёсткий сейчас fit» остаётся открытым, но он самостоятельный и решается не через `☶`.

## 9.2. Runtime добавляет, а не заменяет

`RUNTIME` не подменяет оператор карты. Он **добавляет** выданный оператор к набору выбора. Карта по-прежнему играется по топологии, а установленный `☶` просто всегда присутствует как вариант — и потому всегда может выступить пропуском.

## 10. Что этот закон не решает

```text
1. Круг 8 Nine Circle Run описан как искажение прежнего обмена
   («grave становится публичной реальностью»). Под джокером искажать
   нечего — восьмой круг требует переписывания.
2. Нужна ли джокеру частотная ручка (раз в ход / раз за партию),
   если runtime-вариант окажется слишком сильным.
3. Взаимодействие с козырями, которые сами читают fit
   (MAXIMIZE кастует «пока топология разрешает»).
4. Запертая доска: непустая рука, в которой ни одна карта
   не подходит ни к одному слоту.
```

По пункту 4: единственное записанное условие поражения — пустая рука в момент, когда нужен обычный ход. Случай непустой руки без единого легального хода не описан ни одним законом.

Именно в этой позиции `☶` и работает: он **единственный выход из запертой доски**. Значит его нагрузка прямо зависит от того, как часто доска запирается, и это измеримо до всякой калибровки — долей ходов, где легальных пар нет вовсе.

## 11. Short formula

```text
☶ LOGIC — это не эффект, а разрешение.
Он не случается до хода и не случается после хода.
Он случается в самом ходе: делает легальным то, что законом не было,
и берёт за это весь эффект хода целиком.
```
