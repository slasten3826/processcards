Этот документ называет содержимое девятого шага хода. Сам шаг описан в `TURN_STEP_LAW §10`; здесь сказано, что он делает.

## 1. Девятый шаг — обращение

```text
ход СПРАШИВАЕТ модуль победы
```

Не проверяет сам. Не содержит условия победы. Обращается.

## 2. Границы принадлежат ходу

```text
step_check_begin
   обращение
step_check_end
```

События шага эмитит ход. Модуль про существование шагов не знает.

## 3. Одна точка

```text
обращение эмитится из ОДНОГО места в коде
```

Сейчас границы девятого шага стоят в двух. Пока их две, вторая однажды отстанет от первой.

## 4. Отношение к существующим законам

```text
TURN_STEP_LAW §10   описывает шаг и объясняет, почему он девятый.
                    Не заменяется
WIN_MODULE_LAW §2   форма обращения: подпись TURN
```
