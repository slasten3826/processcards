# Cycle Advance Law

Статус:

```text
canonical table law
current CYCLE branch
supersedes operators/CYCLE.md
```

## 1. Core law

```text
☲ CYCLE

зафиксированная колонка продвигается ВТОРОЙ раз
```

Ядро `☲` в каноне — `iterate fⁿ(x)`. Здесь итерируется не карта и не оператор, а **сам цикл минорной машины**.

## 2. Что такое продвижение

Обычный ход выполняет продвижение один раз, на шаге `UPDATE`:

```text
manifest[i] -> grave
latent[i]   -> manifest[i]
deck        -> latent[i], закрыто
```

`CYCLE` выполняет ту же последовательность ещё раз, в **той же колонке**, по её **новому** состоянию.

Второе продвижение видит результат первого. Это не повтор над теми же картами, а два последовательных шага одной колонки.

## 3. Шаг

```text
EFFECT
```

Первое продвижение — обычный `UPDATE` шага 5. Второе запускается эффектом `CYCLE` на шаге 6. Ни `BURN`, ни новых шагов.

## 4. Ни руки, ни цели

```text
☲ не тянет карт
☲ не сбрасывает карт
☲ не открывает целевую фазу
```

`CYCLE` перестаёт быть оператором руки. Он разрешается немедленно, как `▽ FLOW` и `☰ CONNECT`.

Следствие для экономики руки: `CYCLE` стоит ровно один каст, как большинство операторов, и больше не конкурирует с `☳ CHOOSE`. Они делают разное: `CHOOSE` про руку, `CYCLE` про доску.

## 5. Восхождение козыря

Если поднимающаяся латентная карта оказалась козырем, действует обычный порядок: козырь уходит в `trump flow`, а манифестный слот закрывается из деки по `open_manifest_closure`.

Значит одно продвижение может отправить в очередь **несколько** козырей: поднявшийся, все встреченные при закрытии слота, и новый латентный. Два продвижения удваивают эту возможность.

Верхней границы нет. «Два козыря» — пол, а не потолок.

## 6. Что это даёт игроку

```text
копание       колонка проходится вдвое быстрее, добираясь до того, что под ней
возмущение    латентный ряд — место, где лежат скрытые козыри,
              поэтому CYCLE управляемо повышает частоту козырных событий
```

`CYCLE` — единственный оператор, которым игрок **намеренно заряжает** залп шага `TRUMP`. Буря перестаёт быть погодой и становится решением.

## 7. Цена

```text
дека   два пополнения латента вместо одного,
       плюс закрытия манифеста при встрече козырей
```

`CYCLE` — самый дорогой оператор по расходу колоды. Это и есть плата за копание.

## 8. Что заменяется

```text
operators/CYCLE.md §1  "☲ = perform 1 draw procedure, then discard 1 from hand"
operators/CYCLE.md §3  процедура тяги и сброса
operators/CYCLE.md §4  role split "☰ grows hand / ☲ refreshes hand"
operators/CYCLE.md §5  trump risk через draw procedure
```

Козырный риск не исчезает, а меняет источник: он приходит теперь не от тяги, а от восхождения.

## 9. Open

```text
1. Пустая колода: второе продвижение не может пополнить латент.
   Поведение то же, что при обычном исчерпании, отдельного правила нет.
2. Дубль ☲☲ — обычная карта; отдельного усиленного эффекта не имеет.
3. Грантовая колонка: если зафиксирована она, второе продвижение
   доедает её латентный этаж и колонка исчезает за один ход.
```
